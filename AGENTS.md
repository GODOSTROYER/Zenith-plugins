# Contributor instructions

Read README.md, docs/architecture.md, docs/security.md and docs/verification.md before edits. Keep authority in GODOSTROYER/zenith and distribution here. No database access, cookies, model calls or execution bypasses in the bridge. Generate plugins with npm run build; never edit generated runtimes by hand. Run npm run verify and record actual results and limitations. Do not merge, publish packages or expose services without authorization.
